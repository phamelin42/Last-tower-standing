# Origine des sprites de tour (`assets/tours/`)

Chaque fichier est une **copie identique, octet pour octet**, d'une image d'un pack libre : aucun sprite
n'est retouché. Les licences ont été lues à la source du pack, dans le `Readme.txt` de son archive. Le
détail des choix est dans `docs/skins/SOURCES.md`.

## Spire, packs de tours (Foozle)

Archives téléchargées à la main par Phil depuis https://foozlecc.itch.io/spire-tower-pack-1 (et `-2`, `-3`,
`-4`). `Readme.txt` de chaque archive : « License: (Creative Commons Zero, CC0)
http://creativecommons.org/publicdomain/zero/1.0/ », « Commissioned from: Baldur
(https://twitter.com/the\_\_baldur) », « Distributed by Foozle (www.foozle.io) », « Attribution not required ».
Seules les images de base des tours sont gardées (jamais les fichiers `.aseprite`, les armes, projectiles ni GIF) :
chaque fichier porte les trois niveaux d'une tour côte à côte, un skin en retient un par son `cadre`.
